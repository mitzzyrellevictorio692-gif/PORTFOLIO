# Resume placeholder

There is no `resume.pdf` in this folder yet.

To enable the "Download Resume" button:

1. Export your resume/CV as a PDF.
2. Name it exactly `resume.pdf`.
3. Place it in this `public/` folder (so it is served at `/resume.pdf`).

Until a real file named `resume.pdf` exists here, the Download Resume button
stays disabled and shows a "coming soon" hint instead of linking to a 404.
